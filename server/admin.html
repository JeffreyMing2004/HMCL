NorthStar 内容发布管理

本地打开使用,编辑后下载 JSON 并上传到服务器站点根目录。校验规则与启动器解析器一致。

公告管理(announcement.json)

content 支持 <a href="https://…">链接文字</a> 标记;date 可选。启动器按列表顺序全部平铺展示。

整合包清单(client.json)

支持 HMCL / CurseForge / MultiMC / Modrinth 格式,启动器安装向导自动识别。

自更新清单(update.json)

国内玩家建议镜像到 northstar.mingpixel.net/download/ 并上传 jar。

反作弊清单(anticheat.json)

组件文件列表

发布流程

1. 点击对应页签的「打开服务器上的 xxx.json」,选择上次从服务器下载(或仓库 server/ 目录)的文件。

2. 编辑内容,页面实时校验(必填项、SHA-1 格式、文件名安全、target 枚举),与启动器解析规则一致。

3. 点击「下载 xxx.json」,把得到的文件通过scp/SFTP上传到服务器站点根目录覆盖旧文件:

scp announcement.json user@northstar.mingpixel.net 对应的站点根目录路径/

4. 浏览器访问对应接口确认生效,例如:

curl -s "https://northstar.mingpixel.net/announcement"

发新启动器版本

git tag v1.0.1 并推送 → CI 自动发布 Release → 「自更新清单」页填入新版本号与 jar 直链(建议同时镜像 jar 到 /download/)→ 下载 update.json 上传覆盖。

注意

本页面请只在本地打开使用,不要部署到公网服务器——静态站没有鉴权,谁都能改你的接口内容。
